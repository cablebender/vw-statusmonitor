# VW-Statusmonitor


Lightweight status monitoring dashboard for Windows Server.

## Features

- ICMP/Ping checks
- HTTP/HTTPS checks
- TCP port checks
- JSON API
- Web dashboard
- Configurable check interval
- Runs as a Windows service
- No database required
